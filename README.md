# Project Navigator Desktop

Ein Desktop-Startprojekt für das Projekt "Project Navigator Desktop" auf Basis von React, Vite und Tauri.

## Start

1. `npm install`
2. `npm run dev`

## Build

`npm run build`

## Ziel

Dieses Projekt dient als Ausgangspunkt für die Desktop-Umsetzung des bestehenden Project Navigator.
